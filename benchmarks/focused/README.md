# 已知路径、合并查询与先验证：95 字符候选

2026-10-24 的第二轮推理与执行策略筛选。**没有替换正式 SKILL.md。** [候选快照](../prompts/focused-execution.txt) · [预定计划](plan.json) · [逐次数据](results.json) · [冻结任务](tasks.json)。

## 改动及结果

此前的可见工具轨迹中，多数运行已经只需 6 次模型请求；一次写入后继续编辑发生字符串替换失败，带来额外步骤。本轮将改动落到读取与验证顺序，正文 95 字符：

```text
按验收定位必需信息；路径已知直接读取，独立查询合并执行。信息足够即实现并验证，只有新证据或验证失败才追加分析、读取或修改。不反复复述或比较等价方案；保留复杂任务必要推理、边界检查与全部交付。
```

原版 94 字符与候选使用相同前置信息、模型、High 档位和工具。四个新任务定义，每个两次独立配对，共 16 个会话，均完成质量检查：

- 原版总 token **499,900**，候选 **476,218**，本次减少 **4.74%**。
- 模型请求 **46 → 42**；工具调用 **64 → 60**。
- 未缓存输入 **33,622 → 34,332**（增加 2.11%）；输出 **12,006 → 14,110**（增加 17.52%）；缓存读取 **454,272 → 427,776**。不能把总 token 降幅当作费用降幅。
- 总耗时约 **126.1 → 135.5 秒**，本次没有提速。
- 16 个产物全部通过指定终端测试及外部验收；共 168 次 unittest 方法执行。同一方法在四组重复，不是 168 个独立测试。

按任务汇总的候选 token 变化：联表 **增加 14.83%**，滑动限流 **减少 0.27%**，虚拟路径 **增加 1.95%**，对象合并补丁 **减少 29.12%**。八个配对只赢四个，两个路径配对均未减少。全部运行保留，包含候选的一次工具错误与后续恢复，没有筛掉表现较差的样本。

运行前固定条件：全部 16 次质量通过、合计 token 至少减少 5%、至少赢 6/8 配对、每个任务至少赢一次，并且任一任务合计消耗增加不超过 5%。本轮仅通过质量条件，**不采纳为正式版**。这里的采纳门槛是工程筛选条件，不是统计显著性证明。

## 可观察的行为

发现/列目录调用从 **3 → 1**，但原生文件读取所占模型步骤两组均为 **16**；原版多数已将必要读取合并。原生读取次数 **33 → 34**。这批任务没有显示“多提醒合并读取”能够稳定降低读取步骤；工具总次数下降也未换来稳定的逐任务收益。

native_read_calls/native_read_steps 只统计 read 与 ops_inspect_local_file，不把 shell 内的读取当成原生文件工具；步骤来自工具记录的 step 字段。发现调用统计 glob/ops_glob 及以 ls/dir/Get-ChildItem 开始的命令。完整逐次计数在 results.json，原始私人轨迹不公开，公开汇总不能替代原始调用审计。

## 设计和验收边界

候选先冻结，再创建任务文件。四个任务分别是对象合并补丁、滑动窗口限流、纯词法虚拟路径规范化与左联表；每个任务的明确合同、实现文件名、测试文件名和所需命令对两组完全一致。

使用 Python 标准库 random.Random、种子 2026102402：按任务与重复构成相邻配对区组，随机首轮顺序，第二轮反转，每轮随机任务顺序。完整计划、软件版本及门槛在 plan.json。没有统计功效计算，小样本筛选不能推广为所有任务的收益。

四份初始错误实现均被负对照拒绝；全部 16 个目录在模型运行前执行相同负对照，以平衡 Python 缓存文件。每次最长 240 秒，运行器不自动重试。终端执行、成功结果、模型路由/High 档位与文件完整性均有本机检查。除实现文件外的已知文件冻结；新增文件也会被列为意外改动，Python 测试缓存除外。

环境为 DeepSeek Harness 0.2.1-rc.2 桌面安装包 headless 入口、deepseek-account/deepseek-flash/High、dsh-ops shell/file 0.3.0。两组都只清理启动子进程继承的 PSModulePath；没有修改模型档位、工具清单、权限或全局配置。之后对打包工具配置的只读检查不属于这次干预，也没有把配置变更的收益混入比较。

总 token 为所有已提交 assistant 请求 usage 中的输入、缓存读取、缓存写入和输出之和。没有 usage 的会话命名和未返回 usage 的在途请求不能计入。本轮均正常结束，没有超时。不是账单费用或内部推理 token 的独立计数，没有改变内部推理机制的证据。

本轮与首版无技能 A/B、上一轮 99 字符候选分开统计。本轮没有无技能组、Low 组或宿主工具配置对照；没有 GUI、联网、长会话或生产系统验证。档案哈希仅供私有档案追溯，不能仅凭公开材料独立核验全部模型 usage。

## 本地验收与隔离试用

Python 3.10+，标准库，离线。验收器会执行指定的 Python 代码，只对可信文件使用。

```powershell
python benchmarks/focused/fixture.py evaluate patch benchmarks/focused/artifacts/F08/patcher.py
python benchmarks/focused/fixture.py evaluate limiter benchmarks/focused/artifacts/F04/limiter.py
python benchmarks/focused/fixture.py prepare patch candidate ../focused-candidate-trial
```

prepare 只允许不存在的新目录；生成合成任务与项目级候选技能，不覆盖现有安装。正式默认仍为 v0.1.1。

方法安排沿用 experimental-design 技能的区组与随机顺序指导，文库来源为 Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026), [Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents](https://doi.org/10.48550/arXiv.2609.00065)。该出处不证明本项目提示有效。
