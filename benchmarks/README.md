# 本机探索性对照：2026-10-24

本文件及 results.json 记录 v0.1.0 的无技能 A/B 实验，历史提示快照保存在 [prompts/v0.1.0.txt](prompts/v0.1.0.txt)。v0.1.1 保留同一 SKILL.md；新增的终端、多文件与两轮交接比较单独见 [扩展报告](extended/README.md)，不能与本组汇总混合计算节省率。

## 设计

2 个合成任务 × 2 组 × 2 次重复，共 8 个新会话。CSV 聚合修复覆盖 CSV 引号、BOM、Decimal、空白与非法值；整数半开区间合并覆盖乱序、相邻、包含、零长度、反向区间与输入不变性。任务合同及初始代码见 [tasks.json](tasks.json)。

顺序：T01 CSV 基线、T02 CSV 技能、T03 区间技能、T04 区间基线、T05 CSV 技能、T06 CSV 基线、T07 区间基线、T08 区间技能。每次使用独立目录和相同的任务合同、初始代码及文件工具约束。候选目录增加本仓库的 SKILL.md，并明确要求加载。模型配置固定为 deepseek-account / deepseek-flash / high；所有请求的配置一致。模型具体服务端权重修订未单独核验。

桌面 UI 控制因截图与输入通道故障无法完成；使用同一安装包提供的官方 headless runner。两个入口的启动提示存在差异，因此结果属于 Harness 引擎验证，不属于 GUI 全流程验收。

## 计量

对每个已提交 assistant 请求相加 `usage.totalTokens`；逐条核对它等于 `inputTokens + outputTokens + cacheReadTokens + cacheWriteTokens`。包含技能发现与加载、工具反馈以及推理与答案输出；缓存输入仍计入 token 数。

自动会话命名请求没有提供 usage，因此排除；未上报的失败尝试无法计量。没有单独的推理 token 桶。token 数与账单价格不同，未换算缓存折扣或金额。Agent 耗时来自 turn/start 到 turn/end，不含进程启动。

所有 8 个 Agent 正常完成；工具返回错误 0，档案解码错误 0。候选 T02/T03 通过 skill 工具加载，T05 直接读取技能正文，T08 通过 skill 加载后又读取了一次正文；这些开销都已计入。没有因中途结果修改技能或补跑失败任务。

## 独立验收

每个 CSV 产物通过 119/119，每个区间产物通过 310/310。共 1,716 次检查，实际是 **429 个独立用例在四组产物上重复**，不能当成 1,716 个独立任务。验收器使用固定随机种子。

公开了 8 份代码产物。可以逐个验收，也可以把自己产生的同合同代码传入：

```text
python benchmarks/evaluate.py csv path/to/totals.py
python benchmarks/evaluate.py intervals path/to/intervals.py
```

退出码 0 表示所有用例通过，1 表示验收失败；参数错误为 2。这个脚本会导入指定的 Python 产物执行合成用例，不会调用模型、上传文件或联网。通过这些用例并不证明所有输入都正确。

CSV 合同要求“无数据时返回空字典”。验收器最初把空文本视为缺少表头；首个基线结束后、任何技能组运行前，已统一改成期望 `{}`。该解释对所有组一致，原始任务和技能保持不变。

## 复测方式与限制

使用 [tasks.json](tasks.json) 重建两个相同的项目副本。只给候选项目安装技能，并在新会话中明确调用；两个会话使用相同模型、推理档位、工具配置和任务合同。按交错顺序重复，记录全部步骤 usage，再用本验收器检查产物。

本次题目明确禁止终端与系统命令，模型只使用文件工具；没有覆盖真实编译、测试命令、网络工具、大型仓库或长上下文。只有两个任务族、四个配对，不提供统计显著性或通用收益结论。未与直接粘贴同文提示做消融，所以不能证明技能封装本身优于同文提示。

公开内容只含合成任务、模型生成的代码产物和脱敏数值。原始会话档案不公开，因此 token 数据不能仅凭仓库完全独立核验。
