# 调用示例与推理档位

给出任务目标、约束和验收标准；只加载一份技能正文。
技能不会代替具体要求，也不会豁免必要测试或权限边界。

## 代码修复

```text
请使用 deepseek-efficient 技能。
修复项目中已报告的边界错误，保留公开接口，执行相关现有测试，报告实际结果和未覆盖范围。
```

## 多文件定位

```text
请使用 deepseek-efficient 技能。
根据故障描述定位相关模块，修改最小必要范围；每项结论给出文件依据，执行相关验证。
```

## 后续交接

```text
请提供本项任务的交接摘要：修改了什么、实际执行了哪些验证、还剩什么未覆盖。不要修改文件。
```

## 文件变化后的上下文

已经读取的内容可能被工具、测试或外部操作改变。
判断是否重复读取时，区分“内容仍相同”与“只记得旧内容”；需要验证落盘结果或检查已变更内容时，应保留读取。

## High / Low 属于宿主配置

先固定提示、任务、工具和验收，再通过 Harness 的模型设置对照推理档位。
比较完整请求用量、实际测试结果和失败重试；某次 Low 的答案更短不代表它更可靠或更便宜。
技能本身不会可靠地替你切换推理档位。

本仓库把测试结果与适用范围记录在 [benchmarks/README.md](../benchmarks/README.md)，不把未测模型或工作流写成已支持。

## 可选长日志工具

只在需要保留完整长日志并返回摘要时，明确要求读取 [references/log-output.md](../references/log-output.md)，再决定是否使用随包提供的 scripts/check_result.py。短日志仍可直接看原结果。工具保留原命令与完整日志，返回调用方捕获的退出码、哈希、行号标记和有限尾部。失败时再定位日志，不减少测试。

此能力没有加入默认 SKILL.md；修复后的配对实验中工具返回字符减少，但总 token 增加。见 [研究依据](RESEARCH.md) 与 [实验记录](../benchmarks/research/README.md)。
